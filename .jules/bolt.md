## 2024-05-24 - Optimize FuzzingStatistics aggregations with single-pass iteration
**Learning:** Found an anti-pattern in `FuzzingRepositoryImpl` where multiple statistics (sum, average, min, max) were calculated using separate terminal operations (`sumOf`, `map`, `average`, `minByOrNull`, `maxByOrNull`) on the same `Flow` state collection (`fuzzingResults.value`). This resulted in redundant iterations over the entire list and unnecessary intermediate allocations, causing performance bottlenecks, especially as the number of fuzzing results grew.
**Action:** Replaced multiple iterations with single-pass loops (`forEach`) that calculate all necessary statistics (sums, max/min values, and averages) in one go, preventing redundant iterations and reducing intermediate list allocations. Ensure any new statistical aggregations on long collections follow this single-pass pattern to optimize performance.
