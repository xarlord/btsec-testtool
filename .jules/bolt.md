## 2024-05-24 - Avoid Multiple Terminal Operations in Flow/Collection Pipelines
**Learning:** Chaining multiple terminal operations like `count`, `sumOf`, or `average` on the same collection sequentially (e.g., `allReports.count {...}`, `allReports.sumOf {...}`) results in multiple iterations over the same collection (O(N*M) where M is the number of terminal ops). This pattern prevents short-circuiting and causes redundant iterations, degrading performance and increasing memory allocation for intermediate evaluation blocks when processing large collections of report outputs.
**Action:** Replace sequential terminal operations with a single-pass traversal using a `forEach` loop or `fold`/`reduce` block. Accumulate required aggregated metrics (like draft counts and total vulnerabilities) simultaneously to reduce algorithmic complexity strictly down to O(N).
