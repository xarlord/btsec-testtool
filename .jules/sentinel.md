## 2026-05-12 - Critical Path Traversal Vulnerability in File Export
**Vulnerability:** The `exportAuditLog` function in `ConsentRepositoryImpl` used user-provided input `outputPath` directly with `File(outputPath)` without any sanitization or validation, leading to an arbitrary file write path traversal vulnerability.
**Learning:** File generation functions that construct paths directly from arguments without validating them against allowed base directories (like `context.filesDir`, `context.cacheDir`, or `/tmp`) allow attackers to break out of intended directories by using `/../` sequences or absolute paths.
**Prevention:** To prevent path traversal vulnerabilities during file generation (like exports), always resolve the `canonicalPath` of user-provided paths and verify they match an allowed base directory exactly (`canonicalPath == base`) or strictly begin with the directory plus a separator (`canonicalPath.startsWith(base + File.separator)`) before proceeding. Do not pass unsanitized paths directly to `File()`.
