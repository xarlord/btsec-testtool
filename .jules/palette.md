## 2026-02-07 - Add keyboard submit action to auth input
**Learning:** In Jetpack Compose, configuring `keyboardOptions` (e.g., `imeAction = ImeAction.Done`) and `keyboardActions` (e.g., `onDone`) for text inputs significantly enhances UX by allowing users to submit forms directly from the software keyboard, rather than forcing them to reach for a separate submit button.
**Action:** Always verify if text inputs are part of a simple form submission and implement appropriate IME actions and keyboard actions to streamline the user flow.
