💡 What: Added a 'Clear' trailing icon button (using `Icons.Default.Cancel`) to `OutlinedTextField` components across multiple screens (`AuthorizationScreen.kt`, `SettingsScreen.kt`, `ReportsScreen.kt`). The button only appears when the text field is not empty.
🎯 Why: Enhances micro-UX by providing users an intuitive, single-tap interaction to clear inputs, which is a standard expectation on mobile interfaces.
📸 Before/After: Before, users had to manually backspace or select all and delete to clear inputs. After, a clear icon allows immediate deletion of the entire input.
♿ Accessibility: Included `contentDescription = "Clear text"` on the `Icon` so screen readers properly announce the button's purpose to assistive technology users.
